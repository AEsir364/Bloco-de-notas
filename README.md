# 📝 Bloco de Notas

![Prévia do App](link_para_sua_imagem_ou_gif_aqui.png)

Um aplicativo mobile para Android e iOS, construído com **Flutter**. O objetivo é oferecer uma ferramenta de anotações minimalista, com foco na rapidez e em funcionalidades essenciais como criar, editar, deletar e compartilhar notas.

---

## ✨ Funcionalidades

* **Gerenciamento de Notas:** Crie, edite e delete notas de forma intuitiva.
* **Múltiplas Telas:** Navegação entre uma tela de lista e uma tela de edição dedicada.
* **Persistência de Dados:** As notas são salvas localmente no dispositivo usando `SharedPreferences`, mantendo o conteúdo salvo entre as sessões.
* **Compartilhamento:** Compartilhe o conteúdo da sua nota como uma imagem PNG, gerada dinamicamente com base no texto.
* **Interface Limpa:** Design minimalista e escuro com tipografia monoespaçada.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** [Dart](https://dart.dev/)
* **Framework:** [Flutter](https://flutter.dev/)
* **Pacotes:** `shared_preferences`, `share_plus`, `path_provider`
* **Ferramentas:** `VS Code`, `flutter_launcher_icons`

---

## 🚀 Como Rodar o Projeto

Para rodar este projeto, você precisará do Flutter SDK instalado e configurado, e do VS Code com a extensão do Flutter.

```bash
# 1. Clone o repositório
git clone [https://github.com/AEsir364/bloco-de-notas-simples.git](https://github.com/AEsir364/bloco-de-notas-simples.git)

# 2. Abra a pasta do projeto no VS Code.

# 3. No terminal do VS Code, rode os comandos:
flutter pub get   # Para baixar as dependências
flutter run       # Para rodar o aplicativo no seu dispositivo/emulador
```
